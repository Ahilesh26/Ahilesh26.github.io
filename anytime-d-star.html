Modified Anytime D* Algorithm

Path planning looks solved until you put a real robot in a real environment. A* finds the optimal path — but it finds it from scratch, and if an obstacle moves while the robot is already executing that path, A* has to start over. D* repairs the plan incrementally when the world changes, spending computation only where the graph has been affected. Neither algorithm makes a useful guarantee about how quickly they produce an initial solution — they either give you the optimal path or nothing.

Anytime algorithms break that deadlock. An anytime planner produces a valid (suboptimal) solution immediately, then uses remaining time to improve it. The question I explored: how much can you modify the Anytime D* framework to improve convergence speed in dynamic environments without sacrificing the bounded-suboptimality guarantee?

The Algorithm Family

A* searches from start to goal using a heuristic to prioritise the most promising nodes — complete and optimal but not incremental. D* reverses the search direction and maintains a priority queue of inconsistent nodes; when edges change, only the affected subgraph needs re-evaluation. Anytime D* (AD*) combines D* Lite's incremental replanning with the anytime property: it uses an inflated heuristic (multiplied by a suboptimality factor ε > 1) to find a quick initial solution, then decreases ε over time, refining toward optimality.

The Modification

The modification focuses on how ε is decreased during refinement. Standard AD* decreases ε by a fixed step at each iteration. My modification adapts the step size based on how many inconsistent nodes were resolved in the previous iteration. When many nodes are inconsistent (the environment is changing rapidly), the algorithm holds ε steady rather than forcing an expensive refinement pass. When the graph is stable, it decreases ε more aggressively. This adaptive scheduling reduces unnecessary recomputation in dynamic scenes while still converging when the environment stabilises.

Results

Benchmarked across 50 randomly generated grid maps with dynamic obstacle insertion at random intervals, the modified algorithm reduced total nodes expanded by an average of 18% compared to standard AD* in high-dynamism scenarios. In low-dynamism scenarios the difference was negligible — the correct behaviour; the adaptive schedule falls back to standard AD* when the environment is stable.

Path planning algorithms are easy to understand in a textbook and surprisingly hard to implement correctly. A node that should be inconsistent but isn't will produce a path that looks plausible but isn't optimal — and those failures are nearly invisible without exhaustive ground-truth comparison.
